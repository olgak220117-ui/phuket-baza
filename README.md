# База Пхукета

Каталог новостроек Пхукета: 79 проектов, сгруппированных по районам
и отсортированных внутри района по цене за м² — от низкой к высокой.
Под каталогом — подборка 15 проектов для презентации, охватывающая 9 районов.

Данные взяты из рабочей таблицы. Цифры, площади, проценты и характеристики
проектов не изменялись; текст вычитан только по орфографии и формулировкам.
Часть пропусков дозаполнена: расчётом из самой таблицы и данными открытых
источников — в исходном файле такие ячейки помечены заливкой и примечанием
с обоснованием.

## Что внутри

- `index.html` — весь сайт одним файлом: разметка, стили, данные. Сборка не нужна.
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages.

## Возможности страницы

- Фильтры по району и по типу (кондо, виллы, таунхаусы), поиск по названию
  и застройщику, переключатель «только с ценой за м²».
- Полоса под ценой показывает место проекта на общей шкале цен за м².
- Кнопка «Локация» открывает поиск Google Maps по названию проекта и району.
- В раскрытой строке — поля для своих ссылок: папка на Google Диске и прайс-лист.

**Поля для ссылок работают только на странице артефакта claude.ai.** Хранилище,
которое их сохраняет, живёт там. В копии на GitHub Pages поля видны, но выключены,
с пояснением — это статическая версия каталога.

## Как обновить данные

Данные лежат прямо в `index.html` в двух блоках:

- `<script id="projects" type="application/json">` — все 79 проектов
- `<script id="picksdata" type="application/json">` — подборка из 15

Замените содержимое нужного блока и закоммитьте — Pages пересоберёт страницу сама.
