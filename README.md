# База Пхукета

Каталог новостроек Пхукета: 79 проектов, сгруппированных по районам
и отсортированных внутри района по цене за м² — от низкой к высокой.
Сверху — подборка 15 проектов для презентации, охватывающая 9 районов.

Все данные взяты из рабочей таблицы. Цифры, площади, проценты
и характеристики проектов не изменялись; текст вычитан только
по орфографии и формулировкам.

## Что внутри

- `index.html` — весь сайт одним файлом: разметка, стили, данные. Сборка не нужна.
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages.

## Как обновить данные

Данные лежат прямо в `index.html` в двух блоках:

- `<script id="projects" type="application/json">` — все 79 проектов
- `<script id="picksdata" type="application/json">` — подборка из 15

Замените содержимое нужного блока и закоммитьте — Pages пересоберёт страницу сам.
